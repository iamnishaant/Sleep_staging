# Figures for release v2 (2 Nov 2026)

`figures/output/` holds the original figures (30 Oct, release v1), made by `make_figures.py`. Both are
unchanged. This folder holds the figures that were **wrong or out of date**, regenerated by
`make_figures_v2.py`. Use a figure from here when one exists; otherwise the original in `output/` is
still valid.

```
python figures/make_figures_v2.py          # all 21
python figures/make_figures_v2.py F19      # one
```

Every test number comes from an evaluation file that was already logged, except F15. F15's read is logged
in `figures/TEST_ACCESS_LOG.md`, and the figure reproduces the logged evaluation exactly (33,365 epochs,
accuracy 0.8196, κ 0.7557).

## New figures for the v2 paper (F25–F33)

Every figure below is generated from an existing result file, and none reads the test set. Each answers a
question a reviewer is likely to ask.

| Figure | Question it answers | Headline | Source |
|---|---|---|---|
| **F25** report verification | Does report generation hold up across releases and splits? | v1 dev 30/31, test 29/29; v2 dev 31/31, test 28/29; flawed reports released: **0 in all four**. 95% Clopper–Pearson bars | `deploy/frozen.json`, R3 `dev_summary.json`, P8 `results.json` |
| **F26** architecture ablation | What do EOG and the new branches add, like for like? | 5-fold CV, same labels: base 0.7584 → TF + local context 0.7653 → **full (v2) 0.7763**; Δκ +0.0179 [+0.0095, +0.0263], better on 5/5 folds | `advanced_stage1/cv_summary.json` |
| **F27** missing-channel robustness | What if the eye electrode is missing? | v2 0.756 → 0.744 without EOG, still above v1 (0.718); by cohort SC 0.754, ST 0.746 | `stage3_test_evaluation.json` |
| **F28** against YASA | How does it compare with an off-the-shelf tool on the same nights? | κ 0.701 vs 0.635; v2 higher on 21/31 nights; N1 F1 0.55 vs 0.30. In-domain advantage disclosed | `agentic/reports/r1_yasa_comparison.json` |
| **F29** real recordings (Path B) | Does it work on raw EDF files, end to end? | v2 higher than v1 on 27/31 nights (mean κ 0.673 → 0.701); 30 verified + 1 sent to review (line noise); median 78 s per report | `p2_staging_scorecard_v1/_v2.json`, `p2_scorecards_v2_llama.json` |

Two conventions to state in captions:
- **F26** uses the cited CV summary, the mean of per-fold differences (+0.0179).
  `stage1_analysis.json` pools all epochs and gives +0.0197 [+0.014, +0.026]. Both are valid; cite one
  consistently.
- **F31(b)** uses `ROADMAP V3/results/v3_quality_ci.json`, the cited V3 result. The older
  `agentic/reports/v3_quality_flags.json` used a different method.
